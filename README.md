# 3D Portfolio Drive

Drive a small car through a 3D world and collect hidden project crystals.

## Stack
- Vite + React
- Three.js via @react-three/fiber
- Rapier physics via @react-three/rapier
- Howler (audio, optional)
- Blender -> glTF models

## Run
```bash
npm install
npm run dev
```
