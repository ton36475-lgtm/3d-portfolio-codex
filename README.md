# 3D Portfolio Drive

A 3D portfolio where you drive a small car through a world and collect crystal projects.

## Stack
- Vite + React
- Three.js via @react-three/fiber
- Rapier physics via @react-three/rapier
- Howler (audio ready)

## Run
```bash
npm install
npm run dev
```
